AURE Luxury Wear — V4

This is a static GitHub Pages-ready storefront.

WHAT'S NEW
- Rebuilt the visual system around the supplied sneaker photos.
- Supplied sneaker backgrounds have been removed and the shoes are used as transparent PNG cutouts.
- Every displayed pair is $130 AUD.
- Six product cards with KAYANO 14 / 20 colourway variety.
- Product filters for all pairs, KAYANO 14, KAYANO 20 and light tones.
- Clicking a shoe opens a product panel with size selection, Add to Cart and Buy Now.
- Working demo bag drawer with quantities represented as separate line items and a running total.
- Removed Journal, Our Story and all Instagram / TikTok / YouTube sections.
- Responsive mobile layout.
- No external image hosting; product images are local in assets/products/.

IMPORTANT
The product photos supplied for this build are user-provided images. Only use product names, logos and imagery in a live commercial store if you have the right or permission to use them. Replace the demo prices, stock, policies and checkout with your real business details before taking orders.

GITHUB PAGES
1. Replace the files in your repository with this folder's contents.
2. Keep index.html at the repository root.
3. GitHub Pages can publish static files directly from a branch.
4. If you need a fully static deployment without Jekyll processing, you can add an empty .nojekyll file at the root.
